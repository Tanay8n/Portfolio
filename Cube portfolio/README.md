# 🧩 Rubik's Cube Developer Portfolio

A modern interactive developer portfolio inspired by the logic and elegance of a Rubik's Cube, built by **Tanay Biswas**.

The website features a fully interactive **3D Rubik’s Cube**, smooth animations, dynamic UI elements, and a clean responsive layout to showcase skills, projects, and a unique AI/ML focused background.

---

## ✨ Features

• Interactive **3D Rubik's Cube** built from 27 cubies  
• Drag to rotate the cube  
• Scramble and Solve functionality  
• Smooth animations and modern UI  
• Animated skill cards (HTML/CSS, JS, Python, AI/ML, Cloud)  
• Functional EmailJS contact form  
• Responsive single-page layout  
• Clean and minimal design

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Pure CSS 3D Transforms & JS Matrix Math** (No external 3D libraries)
- **Canvas** (Background particles)
- **EmailJS** (Contact form handling)

---

## 📂 Sections

The portfolio includes the following sections:

- **Hero** – Introduction, typing animation roles, and the interactive Rubik's cube  
- **About** – Developer background (AI & Machine Learning student) and coding statistics  
- **Skills** – 3D visual technology stack showcasing core competencies  
- **Projects** – Featured work showcase  
- **Contact** – Fully integrated contact form

---

## 🎮 Cube Controls

| Action | Result |
|------|------|
| Drag | Rotate the cube freely |
| Scramble button | Randomizes the cube state with animation |
| Solve button | Automatically solves the cube |
